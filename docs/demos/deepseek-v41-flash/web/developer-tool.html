Capabilities

Everything you need to debug distributed systems.

Built from the ground up for high-cardinality, high-throughput workloads. No sampling compromises, no query timeouts, no vendor lock-in.

Sub-second queries

Columnar storage with vectorized execution. Query 30 days of traces across billions of spans in under 200ms — even with high-cardinality attributes.

Tail-based sampling

Keep every error, every slow request, every trace that matters. Drop the noise at the collector — not at the SDK — so you never lose the signal.

Architecture

Built for the scale of modern production.

FLUXTRACE separates ingest from query. Spans land in a write-optimized columnar store, then get compacted into a read-optimized format for fast analytical queries. No shared bottleneck, no query timeouts.

  • Active-active multi-region Ingest and query from any region with automatic failover.
  • Zero-copy compaction Spans are compacted in the background without blocking queries.
  • Cost-optimized retention Hot data in NVMe, cold data in object storage. Query both transparently.
